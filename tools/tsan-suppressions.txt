# ThreadSanitizer suppressions for the CI job that runs the suite under -fsanitize=thread.
#
# Every entry is a known data race in Source/ or Tests/ that is still unfixed. Each block
# starts with a comment saying which race it hides, and CI rejects an entry without one.
# Remove an entry together with the fix for its race.
#
# race_top: matches only the innermost frame of either access, so it is the default.
# race: matches any frame of either stack. It is used only where the racing access sits
# inside a library call (memcpy, a std::deque member, a libc interceptor), so the innermost
# frame is not ours, and the function it names is small enough that hiding its whole call
# tree hides little else.

# UpdateNetworkLoop's reads of the user-update callback and its data, which
# SetUserUpdateThread writes as plain fields (see the settings block below).
race_top:RakNet::UpdateNetworkLoop(

# Empty-queue checks made before the lock is taken, all inside std::deque or std::vector
# members. PopInaccurate reads queue.empty() unlocked. RunUpdateCycleBody reads
# requestedConnectionQueue.empty() unlocked while SendConnectionRequest pushes under the
# lock; the network thread's side is all of RunUpdateCycleBody, so the entry names the
# pushing side. IsBanned reads banList.empty() unlocked while AddToBanList inserts under the
# lock.
race:RakNet::DataStructures::ThreadsafeAllocatingQueue*::PopInaccurate(
race:RakNet::RakPeer::SendConnectionRequest(
race:RakNet::RakPeer::IsBanned(

# Peer-wide settings that the user thread writes as plain fields while the network or
# receive thread reads them. SetIncomingPassword's write is a memcpy.
race_top:RakNet::RakPeer::SetMaximumIncomingConnections(
race_top:RakNet::RakPeer::GetMaximumIncomingConnections(
race_top:RakNet::RakPeer::SetOccasionalPing(
race:RakNet::RakPeer::SetIncomingPassword(
race_top:RakNet::RakPeer::SetIncomingDatagramEventHandler(
race_top:RakNet::RakPeer::OnRNS2Recv(
race_top:RakNet::RakPeer::SetUserUpdateThread(

# The same race as SetUserUpdateThread above, seen from the callback: the network thread
# gets the callback's data pointer with no happens-before edge to the code that built the
# object, so the callback's first touch of it races that construction. Matched on the
# constructing side, so a race of anything the callback calls still reports.

race:Asker::Asker(
race:UpdateThreadGate::UpdateThreadGate(

# completes.
